# Digi-Build
My brother Tommy loves to work with Legos and create masterpieces based off what he sees others create in the Lego community. However, he can only predict what pieces he needs based off the pieces he has, so he can't clearly plan out his entire build. He can only order a few pieces at a time, meaning he is usually waiting months to complete one project and weeks between getting 10-15 pieces that he needs for his build before getting another batch.

This project is intended to solve all that by doing the following

## Version 1.0 - MVP
- Provide a digital space where Tommy can design a Lego build. This means a 3-D space that he can intuitively move his build and add pieces/change colors wherever it makes sense.
- Save and re-open builds that he's been working on so that he doesn't have to re-build the creation every time he wants to update it.
- List all pieces used in the current build along with their colors.

## Version 2.0 - Builds In Progress
- Show how much of a build Tommy has already put together and which pieces he still hasn't put together yet
- Tommy can update this as he gets his pieces from BrickLink so he knows which pieces he has and which pieces he still needs
- Can export this list so Tommy can provide this list to Mom, Santa, Grammy, and whoever else wants to get him Legos!

The following versions contain features that may not be possible with my skillset alone, but here is the order of priority:

## Version 3.0 - BrickLink Integration
- Connect to BrickLink for accurate and up-to-date information on the price of the Lego bricks needed for his projects (Are there APIs for this?)
- Filter out pieces from the list of pieces to search for on brick link to not include pieces that he already has (for this version, he'd have to do that manually)

## Version 4.0 - Lego Inventory Management
- Create an inventory of all the Legos that Tommy has (tough - will need Tommy's help for this!)
- Automatically determine which Legos Tommy owns and disclude them from the list to get from BrickLink
- Quickly add the lego pieces of a new set by either recoginizing an existing set or something in the manual when he gets a new Lego set

## Version 5.0 - Build Step Generation
- Determine the steps needed to build a particular Lego build
- Display those steps similar to a Lego manual

## Version 6.0 - Shareability
- Provide a way to share builds, pieces lists, and build steps intuitively
- Really open this project to being open-sourced so others in the Lego community can add changes to continue to make this project great!

In the end, some or all of this may not be possible for me to do alone, but it will at the very least test my skills as a developer and hopefully make my brother's life a little bit better!
